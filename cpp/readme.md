## 🛠️ How to Run

Make sure you have a C++ compiler like [`g++`](https://www.msys2.org/) installed.

> Basic Requirements:

- input.txt and output.txt file should exist in the same directory.

```
# Example:

c++
|
|- input.txt
|- output.txt
|_ <file_name>.cpp
```

- If output.txt is not found, then it'll automatically create one.

> To compile and run any file:

```
g++ <file_name>.cpp -o <output_name>
./<output_name>
```
